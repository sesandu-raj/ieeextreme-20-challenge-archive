# Welcome to IEEEXtreme 20.0

## Task

This is the optional introductory task: print a message for the IEEEXtreme team. There is no input, and the task is not scored.

## Approach

Write a program that emits a short text message (at most 200 words) and then terminates. Since no input is provided, no parsing or algorithm is needed. Ensure the output is plain text and stays within the stated word limit.

The contest introduction also emphasizes following each challenge's AI-use label and editor rules; those rules are separate from the simple output requirement here.
